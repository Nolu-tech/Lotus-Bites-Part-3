Lotus Bites Website Project

Project Overview

Lotus Bites is a food website developed as part of the WEDE5020 Web Development Introduction module. The website provides information about the business, displays its food menu and allows customers to make enquiries and place orders.

The project demonstrates the use of HTML5, CSS3 and JavaScript to create an interactive and responsive website.

Website Purpose and Target Audience

The purpose of the website is to introduce customers to Lotus Bites, showcase available food products and make it easier for customers to enquire about products and place orders.

The target audience includes individuals, families and customers interested in ordering sushi, noodles, combo meals, drinks and desserts.

Website Pages

The website consists of the following pages:

Home Page (index.html): Introduces the business and displays featured products and a food gallery.
About Page (about.html): Provides information about the business, its mission and the products offered.
Products Page (products.html): Displays the food menu with product categories, search and price sorting.
Contact Page (contact.html): Provides contact information and a contact form for customer enquiries.
Enquiry/Order Page (enquiry.html): Allows customers to enter their details and submit food orders through WhatsApp.
Technologies Used

The following technologies were used:

HTML5: Provides the structure and content of the website.
CSS3: Controls the website layout, styling and responsive design.
JavaScript: Adds interactive functionality, including product filtering, searching, sorting, gallery lightbox functionality and form processing.

Website Features

The website includes the following features:

Navigation between website pages.
Responsive website layout.
Product search functionality.
Product category filtering.
Price sorting from lowest to highest and highest to lowest.
Interactive food gallery with a lightbox.
Interactive map on the Contact page.
Customer contact form with validation.
WhatsApp ordering functionality.
SEO title tags, meta descriptions and keywords.
Alternative text for website images.

How to Run the Website

Download or clone the project repository from GitHub.
Open the project folder in Visual Studio Code.
Ensure that all project files and folders are available.
Open the index.html file.
Use the Live Server extension in Visual Studio Code to launch the website in a browser.
Navigate through the website using the navigation menu.
